# SHABAAN Online Training — Frontend

Arabic RTL landing page for SHABAAN's online personal training / nutrition coaching service. Vite + React 19 + TypeScript, subscription/contact actions go through WhatsApp deep links (`wa.me`).

## Commands

- `npm run dev` — start the dev server (http://localhost:5173)
- `npm run build` — production build to `dist/`
- `npm run serve` — preview the production build locally
- `npm run typecheck` — TypeScript check with no emit

## Deploying

Deployed as a static Vite build on Vercel. `vercel.json` rewrites all routes to `index.html` so client-side routing (`wouter`) survives a hard refresh on `/admin` etc.

## Structure

- `src/App.tsx` — the entire public landing page (hero, plans, gallery, testimonials, FAQ, footer) as one component.
- `src/components/ui/` — shadcn/radix UI primitives, generated by tooling; treat as a component library, not hand-maintained app code.
- `public/assets/` — static images/audio used by the landing page.
