# SHABAAN Online Training — Frontend

Arabic RTL landing page for SHABAAN's online personal training / nutrition coaching service. Vite + React 19 + TypeScript, subscription/contact actions go through WhatsApp deep links (`wa.me`). Includes an `/admin` dashboard for managing a subset of the landing page's images/voicenotes, backed by the separate `shabaan-backend` API.

## Commands

- `npm run dev` — start the dev server (http://localhost:5173)
- `npm run build` — production build to `dist/`
- `npm run serve` — preview the production build locally
- `npm run typecheck` — TypeScript check with no emit

## Environment variables

- `VITE_API_URL` — base URL of the `shabaan-backend` deployment, no trailing slash and no `/api` suffix (that's added automatically). Defaults to `http://localhost:8080` if unset. See `.env.example`.

## Deploying

Deployed as a static Vite build on Vercel. `vercel.json` rewrites all routes to `index.html` so client-side routing (`wouter`) survives a hard refresh on `/admin` etc. Set `VITE_API_URL` in the Vercel project settings to the deployed backend's URL — and make sure that backend's `FRONTEND_URL` env var includes this frontend's deployed domain, or the admin login's cross-origin cookie request will be rejected by CORS.

## Structure

- `src/App.tsx` — the public landing page (hero, plans, gallery, testimonials, FAQ, footer) as one component. Reads `gallery-N`/`testimonial-N` image/audio URLs from the backend via `useAssets`, falling back to the bundled `public/assets` files for any slot with nothing uploaded yet (or if the request fails).
- `src/pages/admin-login.tsx`, `src/pages/admin-dashboard.tsx` — `/admin` and `/admin/dashboard`. The dashboard is client-side gated on `GET /api/auth/me` and lets the admin add, replace, or delete gallery photos and testimonial voicenotes.
- `src/lib/api.ts` — fetch wrapper (`credentials: 'include'` for the auth cookie) plus the Cloudinary direct-upload helper.
- `src/lib/slots.ts` — the slot ID ↔ static-fallback-file mapping shared by the public page and the dashboard.
- `src/hooks/use-auth.ts`, `src/hooks/use-assets.ts` — react-query hooks for auth state and asset data/uploads.
- `src/components/ui/` — shadcn/radix UI primitives, generated by tooling; treat as a component library, not hand-maintained app code.
- `public/assets/` — static images/audio used by the landing page, including fallbacks for the 12 admin-managed slots.
